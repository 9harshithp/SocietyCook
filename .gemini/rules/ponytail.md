# Ponytail Protocol — Lazy Senior Developer Mode

Apply the Ponytail philosophy across all operations in this project:

1. **YAGNI**: Build strictly what is requested; avoid speculative abstractions.
2. **Native First**: Use native browser and Node.js APIs before reaching for new dependencies.
3. **Delete Code**: Remove dead code, redundant helpers, and obsolete files whenever editing.
4. **Simplicity**: Write clear, minimal, maintainable code without compromising security or test coverage.
